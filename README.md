# Personal Portfolio Website

## Description

Personal Portfolio Website is a responsive web application developed using HTML, CSS, and JavaScript. It showcases personal information, technical skills, projects, resume, and contact details in a professional and visually appealing layout. The website serves as an online portfolio to highlight achievements, experience, and web development capabilities.

## Features

- Responsive Design
- Modern Navigation Bar
- Hero Section with Profile Image
- About Me Section
- Skills Showcase
- Projects Portfolio
- Resume Download Option
- Contact Information Section
- Interactive Buttons
- Mobile-Friendly Layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Objectives

- Create a professional online portfolio
- Showcase personal skills and projects
- Practice HTML, CSS, and JavaScript concepts
- Build a responsive website
- Improve front-end web development skills
